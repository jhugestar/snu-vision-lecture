Update rules

g = ∇L(θ)  ·  η = learning rate  ·  ε = 1e-8

SGD

θ ← θ − η·g
Step size follows the raw gradient: too big where it is steep, too small where it is flat.

SGD + Momentum

v ← β·v + g
θ ← θ − η·v
A running sum of gradients: opposite signs cancel, the same sign builds speed.

RMSProp

s ← ρ·s + (1−ρ)·g²
θ ← θ − η·g / (√s + ε)
Divides each coordinate by its recent gradient size, so every axis moves about η per step.

Adam

m ← β₁·m + (1−β₁)·g
s ← β₂·s + (1−β₂)·g²
θ ← θ − η·m̂ / (√ŝ + ε)
Momentum and RMSProp together. m̂ = m/(1−β₁ᵗ), ŝ = s/(1−β₂ᵗ) undo the zero start.
