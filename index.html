Interactive Demos for Studying
Computer Vision and Machine Learning Algorithms

Hanbyul Joo  |  Visual Computing Lab, Seoul National University

Every topic below is a small, self-contained page you can play with: move the sliders, change the parameters, and watch each step of the algorithm respond. Built for the computer vision courses at Seoul National University, and free to use in your own class or study.

About these demos

All demos were built with vibe coding using Claude Code — no demo code was written by hand; the entire implementation was generated through natural language conversation. This project is an initial effort to explore how AI can enhance the teaching and learning experience. I believe we are at a pivotal moment to rethink how we leverage AI tools to create more impactful educational content.
